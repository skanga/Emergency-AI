## Operational limits

- Native Windows/macOS runtime upgrades were not exercised here. Platform-dependent tests remain skipped as reported.
- Large model downloads/real inference and real Kiwix binary/ZIM upgrade probes were not executed. Tests validate their process/protocol handling with fixtures; the loader-environment test is real.
- Updates are individual artifact transactions, not atomic cross-component dependency groups. Jointly incompatible model/runtime changes require a staged manual migration.
- Existing document indexes and edition-scoped source policies require a reviewed migration. Missing publisher checksums, unknown/custom provenance, foreign platforms and in-use/legacy-linked Python installations receive manual or blocked status.
- Full temporary-space estimates and cross-component dependency plans are not shown in the initial confirmation. Download sizes are shown; staging/activation checks actual storage needs.
- Adoption is explicit for existing model/ZIM files; setup is not silently repurposed into upgrade.
- Operational success is not advice-quality validation. Every transaction records `advice_evaluation: not_run`; the durable advice eval remains a separate task.
